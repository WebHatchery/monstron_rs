# Hatchspire credits — approval draft

Hatchspire is developed in the WebHatchery RustGames workspace using Rust, macroquad, and the shared
macroquad-toolkit.

The current build embeds project-authored game data, the Hatchspire title image, and generated
visual atlases. Creator identity, generation/source records, ownership or commercial-license basis,
required attribution, modifications, and publisher approval are not yet complete for every visual
asset. A 37-input provenance ledger is maintained with the repository's release records.

No public credit list is approved yet. The rights holder must add the correct legal publisher,
creator names, generation disclosures, and any required third-party attribution before release.
This draft is intentionally not a claim that unresolved material may be distributed.
