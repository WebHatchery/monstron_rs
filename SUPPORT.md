# Hatchspire preview support

No public support address has been approved. Internal testers should use the private invitation
channel through which they received this build. This file must be updated with the publisher's
approved support route before public release.

When reporting a problem, include:

- the Hatchspire version shown under **Settings → Help & Support**;
- the exact on-screen message and what you tapped immediately beforehand;
- your Windows version, display resolution, and display scale;
- whether the problem still happens after restarting;
- `crash_log.txt`, if it exists beside the saved-camp file; and
- the saved-camp file only when you are comfortable sharing its local gameplay data.

The game never uploads logs or saves automatically. Remove any material you do not want to share.
Do not publish a save or log openly; send it only through the approved support route.
