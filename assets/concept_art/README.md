# Hatchspire Concept Art

This folder contains a focused concept-art pass for Hatchspire's visual direction. The images are reference art, not runtime assets.

## Session set

- `hatchspire_camp_keyart_v1.png` — rebuilt monster haven beneath the ruined tower; establishes the camp/tower relationship and the warm-vs-cool lighting language.
- `moss_gate_floor_concept_v1.png` — first-floor Moss Gate exploration space; establishes broken traversable platforms, a safe CAMP shelter, and wet mossy ruins.
- `companion_roster_sheet_v1.png` — core companion silhouettes for Mossy Slime, Rillfin, Rootling, and Glowmoth; intended as a reference for portraits and future sprite passes.
- `mirror_matriarch_threshold_v1.png` — mid-tower boss threshold; establishes the Mirror Matriarch as a plant-and-crystal guardian in a flooded ruin.

The pass keeps the existing Hatchspire palette: deep navy and blue-green shadows, moss and leaf greens, warm amber firelight, and bright violet, teal, and mint monster accents.
